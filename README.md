# Atlas-Lite

**Windows 桌面自動化(RPA)+ Python 腳本流程引擎。零 LLM 也能完整運作。**

從 [Atlas](../Atlas) 抽取而來,只保留兩種核心節點:

| 節點 | 做什麼 |
|---|---|
| **桌面自動化** | 錄製滑鼠鍵盤 → 回放。CV 錨點比對 / OCR / UIA 三層定位 |
| **Python 腳本** | 執行你自己的 `.py`,步驟間可傳結構化資料 |

外加流程控制:條件分支、人工確認、排程、Webhook/資料夾觸發、Telegram 通知。

---

## 跟 Atlas 的關係

Atlas-Lite 是**獨立專案**,不是 Atlas 的模組或 submodule:

- 獨立 git repo、獨立 venv、獨立資料目錄
- 不 import Atlas 的任何程式碼
- 程式碼是**複製過來改**的,兩邊各自演進

檔案若源自 Atlas,檔頭會註明來源,方便日後互相回補修正。

| | Atlas | **Atlas-Lite** |
|---|---|---|
| 定位 | AI 工作流編排(LLM 為核心) | **純自動化執行引擎** |
| LLM | 必要 | **完全不需要** |
| 沙盒(WSL+Docker) | skill 節點需要 | **不需要** |
| 後端埠 | 8014 | 8020 |
| 前端埠 | 3012 | 3020 |

---

## 為什麼「無 LLM」是可行的

抽取前做過完整依賴盤查,結論:

- **純腳本執行路徑零 LLM** —— 從 API 到 `subprocess` 中間沒有任何模型呼叫
- **桌面自動化的 15 種動作全部零 LLM** —— 點擊 / 輸入 / 熱鍵 / 拖曳 / 捲動 / 等待 / 斷言 / 條件分支 / 重試迴圈
- **腳本節點本來就在 host 執行**,且刻意與後端 venv 脫鉤,沙盒只服務 LLM 生成的程式碼

LLM 在原專案裡負責的是「**產生**工作流」與「**看圖判斷**」,不是「執行」。Atlas-Lite 把執行的部分完整保留。

## 系統需求

| 項目 | 版本 | 必要性 |
|---|---|---|
| Windows | 10 / 11 | 必要(桌面自動化只支援 Windows) |
| Python | 3.11 - 3.13 | 必要 |
| Node.js | 18+ | 必要(前端) |
| NVIDIA GPU(6GB VRAM 以上) | — | **選用**,只有要用 GUI 定位模型才需要 |

**不需要** WSL2、Docker、任何 LLM API Key。

## 選用:GUI 定位模型(地端 VLM)

桌面自動化預設用**錨點圖 + CV 比對**找按鈕。錨點會因為主題色改變、視窗縮放、對方軟體改版而失效。這個模型讓你改用**一句話描述**定位:

```yaml
- type: click_image
  vlm_mode: grounding
  vlm_prompt: "工具列上的排序按鈕"
```

模型只回答「**在哪裡**」,動作種類仍由 YAML 決定;失敗自動退回 CV 比對。

**全程地端推論,不呼叫外部 API、截圖不出網路。**

### 硬體與效能(2026-08-06 Windows host 實測)

| 可用 VRAM | 自動採用 | 峰值佔用 | 定位誤差中位數 | 每次推論 |
|---|---|---|---|---|
| 12GB 以上 | fp16 | 9.65 GB | 3.0 px | 5.1 秒 |
| 6GB 以上 | int4 | 3.68 GB | 3.6 px | 6.0 秒 |
| 低於 6GB | 不啟用 | — | — | — |

精度由系統依可用記憶體自動選,使用者不需設定。量化幾乎不影響精度(3.0 vs 3.6 px)。

**安裝**:

```cmd
plugins\vlm_grounding\setup.bat
```

需要 8.9GB 下載、8.3GB 磁碟、約 2.9GB 的 CUDA PyTorch。僅支援 NVIDIA。

### 已知限制

- 模型**不會承認找不到目標** —— 問它畫面上沒有的東西,它會指一個最像的位置。系統會拿錨點圖做局部比對擋掉,但那是粗篩,擋得住「指到畫面另一區」,擋不住「指到隔壁很像的按鈕」
- 描述**不要用否定句**。「不是視窗關閉鈕的那個 X」會被忽略修飾語而點錯,改用正面且獨特的特徵
- 破壞性動作(刪除、送出)**請在後面加 `assert_image` 驗證結果**,不要單獨依賴
- **不要拿它讀畫面上的文字** —— 長字串會編造。讀值請用 OCR 或直接回資料源

## 快速開始

```cmd
launch.bat
```

首次執行會自動建立 venv、安裝相依、啟動前後端。

---

## 安全性

- API **沒有認證**,而且腳本節點能執行任意 Python
- 因此預設只綁 `127.0.0.1`。**綁 `0.0.0.0` 等於對區網開放一個可執行後門**
- 被自動化的應用程式密碼請放 `secrets vault`,不要寫在 YAML 裡
